CSV Format Reference

The CSV header row must include columns matching the WCGtv schema:

id,created,title,dateRecorded,expiryDate,producer,length,category,community,sourceCode,share,filename,comments
Column Specifications:
  • title: Required string
  • dateRecorded: Required date (YYYY-MM-DD)
  • expiryDate: Optional date (YYYY-MM-DD)
  • producer: Required string
  • length: Required time format (HH:MM:SS)
  • filename: Required file name with valid extension (e.g. show.mp4)
  • category: Optional category (e.g. sports, arts/music)
  • community: Optional comma-separated list of communities
  • share: Optional comma-separated list of share targets
  • sourceCode: Optional source code string
  • comments: Optional notes (max 255 chars)
