API Authentication Quickstart

You can authenticate your HTTP requests by providing your API key using either of these methods:

1. X-API-Key Header
curl -H "X-API-Key: wcgtv_..." \
  https://example.com/api/v1/programs/
2. Authorization Header
curl -H "Authorization: Api-Key wcgtv_..." \
  https://example.com/api/v1/programs/

Note: By default, the /api/v1/programs/ endpoint only returns approved / signed-off programs to external systems. To query unapproved drafts or pending reviews, specify ?include_pending=true or filter by ?status=....
